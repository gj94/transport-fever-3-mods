# Middle portable colour release selection

The frozen cohort and colour addendum cover thirteen material-only revisions. This publication selection releases only the following stations with matching accepted native gates: MQO, OCR, STKT, QLN, IRP, MYY, VAK, PRND, KVU, KPY, KFI, AMY, CRY.

All thirteen matching native/source-image gates are accepted. EVA and PVU are outside this frozen cohort and are not included in this release selection.

Use the per-station `CURRENT_PORTABLE_EXPORT.md` notes and `PORTABLE_EXPORT_SELECTION.json` records. Original frozen source/manifests/README bytes remain intact. First-main packages omit superseded white-fallback archives; optional historical-only manifests preserve those exact bytes.
