# Tumboli (TMPY)

Open TMPY_coastal_station_v02.blend. All resources are packed and units are metres. See renders/ for overall, frontage, platform/track and reconstructed-interior views. No trains.

Read SOURCES_AND_UNCERTAINTIES.md before treating this as a real-world layout. Source plan, inferred elements, dated photos and incomplete evidence are distinguished. Inspect QA_BUILD.json and render sidecars for provenance.

The model can be freely edited. Platform heights, hidden interiors and building dimensions are approximate. This asset is not suitable as an engineering/safety drawing.
