# AROR editable source checkpoint

Immutable recovery checkpoint. The editable scene is built; final gallery, export and independent quality review are pending. This is not a final release. No source reference photographs are distributed.

Open `AROR_coastal_station_v01.blend` in Blender. Exact source SHA256: `17d63e42002c4418fdaa5a6b474905929b18de8dd106013cfa2b704cf1c9fe84`. Source-specific mapped geometry, build/render/export scripts and original sign artwork are included.
