The halt closed10 July2017. This asset preserves the mapped rail corridor near the legacy locator, with interpretive labels. A separate, explicitly unplaced scene reconstructs the photographed August2016 facade and a modest furnished historical interior. This is not an active station or a verified surviving building. No exact historical platform footprint or remnant location is claimed.
