# Detailed station rebuilds · work in progress

## [Open the image review gallery](review_gallery/README.md)

The gallery shows selected reviewed interior and physical-track previews from TVC, NCJ and ERS, plus labelled yard coverage. Click any picture for the full-size image.

These are editable visual reconstructions with full station-yard and interior work underway, not survey-certified historical models. Architecture and present-day map evidence have different dates. No trains or rolling stock are included. Review identifiers on plans are not operational railway numbers.

- [TVC sources and scope](tvc/README.md)
- [NCJ sources and scope](ncj/README.md)
- [ERS sources and scope](ers/README.md)
- [Evidence and limitations](research/layout_evidence_audit.md)

This backup branch contains incremental WIP checkpoints. A newer script may precede the next scene rebuild; the gallery records its own image provenance. Large editable scenes use exact-byte `.blend.parts` folders: run the included `reassemble.py` to reconstruct and SHA256-verify the whole `.blend`. Individual parts cannot be opened as Blender files. Main remains the previously published version until final review is complete.

No new licence is granted for generated assets; relevant third-party source obligations are documented in station notices.
